# Tracepoint

Tracepoint is a Blue Team DFIR & OSINT toolkit that streamlines investigations with case management, unified analysis of IPs, domains, and files, automatic IOC extraction, EXIF geolocation, suspiciousness scoring, and structured JSON/CSV reporting.

## Features

- **Case management** – Organize findings under a case name
- **File analysis** – EXIF metadata, GPS extraction, and hashing (MD5, SHA1, SHA256)
- **IP intelligence** – Geolocation, reverse DNS, VirusTotal, AbuseIPDB, Shodan
- **Domain & URL analysis** – WHOIS lookup and URL reputation
- **Unified investigation** – Run multiple checks on a target automatically
- **IOC extraction** – Pull IPs, URLs, domains, and hashes from raw text/logs
- **Suspiciousness scoring** – Generate a threat score based on collected data
- **Reporting** – Export results to JSON or CSV
